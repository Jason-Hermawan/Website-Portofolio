Dwellth - Apartment Recommendation & Search System

Ringkasan Proyek:
Proyek Dwellth (Apartment Recommender and Price Predictor) dibangun dengan arsitektur web modern mengombinasikan backend FastAPI serta frontend Vue.js. Pada sisi pemrosesan data dan AI, sistem memanfaatkan algoritma K-Means Clustering untuk mengelompokkan apartemen ke dalam segmen pasar seperti Budget, Premium, atau Fungsional, serta algoritma Random Forest Regressor untuk memprediksi harga sewa wajar dan mengidentifikasi hunian bernilai tinggi (High Value Deal). Dataset untuk project ini diambil dari kaggle, yang berisi apartment/hunian yang berlokasi di amerika serikat. Masing masing dari hunian tersebut mempunyai deskripsi karakteristik seperti harga sewa/huni,jumlah kamar tidur , kamar mandi dan fitur lainya yang digunakan untuk mencari hunian yang cocok dengan selera pengguna menggunakan content based filtering

EcoSort: Waste Classification System

Ringkasan Proyek:
Proyek EcoSort merupakan sistem klasifikasi sampah Organik dan Anorganik otomatis berbasis web yang dibangun menggunakan kombinasi ekstraksi fitur visual seperti Color Histogram, Local Binary Patterns (LBP), dan Histogram of Oriented Gradients (HOG), serta diproses menggunakan teknik pengurangan dimensi Principal Component Analysis (PCA). Pemodelan utamanya mengimplementasikan Support Vector Machine (SVM) dengan kernel RBF yang berhasil meraih akurasi sebesar 96,22% dan waktu inferensi cepat 15,07 ms per gambar. Seluruh alur sistem dikembangkan dengan bahasa Python memanfaatkan pustaka OpenCV dan Scikit-Learn, lalu dideploy secara interaktif menggunakan Streamlit

Python OpenCV Scikit-Learn SVM (RBF) PCA Streamlit

IDTM: Indonesian Discord Toxicity Monitor Bot

Ringkasan Proyek:
Proyek IDTM (Indonesian Discord Toxicity Monitor) merupakan sistem bot Discord berbasis AI yang dirancang untuk melakukan moderasi otomatis dan deteksi teks berbahasa Indonesia secara real-time. Menggunakan dataset percakapan komunitas yang mencakup empat kategori (Neutral, Violence, Racist, dan Harassment), proyek ini melakukan eksperimen benchmarking terhadap enam arsitektur model machine learning dan NLP, yaitu Naive Bayes, Logistic Regression, SVM, FastText, BiLSTM, dan IndoBERT. Model Transformer IndoBERT terpilih sebagai model terbaik setelah mencapai weighted F1-score sebesar 84,17% dan nilai AUC 0,9655. Dalam penerapannya, bot ini mampu memberikan peringatan publik otomatis untuk prediksi dengan tingkat keyakinan di atas 80% dengan kecepatan inferensi di bawah 2 detik, serta menyediakan fitur audit log untuk kebutuhan moderator server.

Python NLP IndoBERT PyTorch Transformers Discord.py
