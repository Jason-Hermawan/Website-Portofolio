PROJECT DETAILS

Dwellth - Apartment Recommendation & Search System

Project Overview

Proyek Dwellth (Apartment Recommender and Price Predictor) dibangun dengan arsitektur web yang mengombinasikan backend FastAPI serta frontend Vue.js. Pada sisi pemrosesan data dan AI, sistem memanfaatkan algoritma K-Means Clustering untuk mengelompokkan apartemen ke dalam segmen pasar seperti Budget, Premium, atau Fungsional, serta Random Forest Regressor untuk memprediksi harga sewa wajar dan mengidentifikasi hunian bernilai tinggi (High Value Deal). Dataset proyek ini berasal dari Kaggle dan berisi data apartemen/hunian di Amerika Serikat. Sistem juga menggunakan Content-Based Filtering untuk membantu pengguna menemukan hunian berdasarkan karakteristik dan preferensi mereka.

Python FastAPI Vue.js K-Means Random Forest Recommendation System

PROJECT DETAILS

EcoSort: Waste Classification System

Project Overview

EcoSort merupakan sistem klasifikasi sampah organik dan anorganik otomatis berbasis web. Sistem ini menggunakan ekstraksi fitur visual seperti Color Histogram, Local Binary Patterns (LBP), dan Histogram of Oriented Gradients (HOG), serta Principal Component Analysis (PCA) untuk pengurangan dimensi. Model utamanya menggunakan Support Vector Machine (SVM) dengan kernel RBF yang berhasil meraih akurasi sebesar 96,22% dan waktu inferensi 15,07 ms per gambar. Sistem dikembangkan menggunakan Python, OpenCV, dan Scikit-Learn, kemudian diintegrasikan dengan Streamlit.

Python OpenCV Scikit-Learn SVM (RBF) PCA Streamlit

PROJECT DETAILS

SentimentBot

Project Overview

SentimentBot merupakan sistem bot Discord berbasis AI untuk melakukan moderasi otomatis dan mendeteksi teks berbahasa Indonesia secara real-time. Proyek ini menggunakan dataset percakapan komunitas dengan empat kategori: Neutral, Violence, Racist, dan Harassment. Eksperimen dilakukan dengan enam arsitektur machine learning dan NLP, yaitu Naive Bayes, Logistic Regression, SVM, FastText, BiLSTM, dan IndoBERT. IndoBERT menjadi model terbaik dengan weighted F1-score sebesar 84,17% dan AUC 0,9655. Bot juga memberikan peringatan otomatis untuk prediksi dengan confidence di atas 80% dan menyediakan audit log untuk moderator server.

Python NLP IndoBERT PyTorch Transformers Discord.py
